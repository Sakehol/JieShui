## 接水 v1.0.3 · 扫码这次是真的改了

这一版把扫码整个重做了一遍。前面几版一直在调解码参数，但问题从来不在解码 —— 在**取景**。

### 改了什么

**1. 画面不再被放大**

以前预览是 `cover`（铺满屏幕、多余的裁掉）。手机竖屏 + 摄像头横流，横向直接裁掉 74%，
等效放大 3.85 倍。你看到的是个"怼到脸上"的画面，自然觉得离得太近、要往后退 ——
一退，二维码在画面里就变小，反而更扫不上。现在改成 `contain`：整幅画面完整显示，一像素都不裁。

**2. 看见的就一定能认**

以前只解取景框那一块。画面整幅显示后，四角的码你明明看得见，程序却根本没去看它。
现在解码也取整幅。实测把码贴在画面右上角：整幅解认得出，只裁中心块认不出。

**3. 扫不出来就拍张全分辨率照片**

预览流的分辨率有天花板（多数手机网页给到 1920x1440 就到顶）。码占画面 8% 时，
在预览里只剩 86px，25 个模块摊下来 3.5px/模块 —— 非常勉强。
现在连续扫两三秒没结果，会自动拍一张全分辨率静态照片再识别（也能点一下画面手动触发）。
同一个镜头，照片能到 4000x3000，比预览多一个数量级的像素。

**4. 修好了反色兜底（它之前从未生效）**

深底亮码、反光贴纸这类，需要把像素取反再解一遍。上一版写的是 jsQR 的
`inversionAttempts: 'onlyInvert'`——这个值会直接抛
`Cannot read properties of undefined (reading 'height')`，异常被外层 catch 吞掉，
所以那段兜底一直在空转。改成 `invertFirst` 才真正跑起来。

**5. 网页端扫码页不再是一块黑底**

取景框之外现在是模糊的同一路画面，不再是纯黑。

**6. 安卓端对齐**

预览不裁切、解码整幅、拍照兜底、变焦归位、扫到震动 —— 两端现在是同一套逻辑。

### 实测

`tools/ScanCoreTest.java` 在 JVM 里直接跑生产代码 `ScanCore`：

| 二维码占画面 | 1280x720 | 1440x1080 | 1920x1080 | 2048x1536 |
| --- | --- | --- | --- | --- |
| 12% | ✓ | ✓ | ✓ | ✓ |
| 10% | ✗ | ✗ | ✓ | ✓ |
| 8% | ✗ | ✗ | ✓ | ✓ |
| 7% | ✗ | ✗ | ✗ | ✓ |
| 6% | ✗ | ✗ | ✗ | ✓ |

能认出的最小占比：720p → 12%，1080p → 8%，1536p → 6%（数字越小，能站得越远）。

## 安装

**网页版**（推荐，无需安装）：<https://jieshui.pages.dev>
用手机浏览器打开即可，也可以「添加到主屏幕」当 App 用。

**安卓 APK**：下载下方的 `jieshui.apk`（285 KB）。
- 与旧版签名相同，可直接覆盖安装
- 无需 root，不申请多余权限（只有相机、网络、振动）
- 首次使用需要填入你的 token —— 网页版和 APK 通用，从官方 App 里导出即可，方法见
  [技术文档](https://github.com/Sakehol/JieShui/blob/main/docs/TECH.md)
