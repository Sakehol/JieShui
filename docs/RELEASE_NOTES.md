## 接水 v1.1.2 · 从「常用设备」进去也不会再有那个不灵的开阀键

v1.1.1 把扫码页那三个假按钮删干净了，但只删了**一条路径**。设备页其实有两个入口：

| 入口 | v1.1.1 之前 |
|---|---|
| 扫机器上的码 | 已删三键，走四态 ✅ |
| 首页「常用设备」点进去 | **还留着**「准备就绪 / 点击下方按钮开始接水 / 开始接水」❌ |

那个「开始接水」点了只会让客户端本地再发一次 unlock，服务端根本没有开阀接口，水一滴都不会出。这一版把两个入口合成一条：**不管从哪进来，设备页都直接开阀，然后只如实反映机器状态。**

### 现在手机上只有这四个状态

| 你在机器上做的 | 手机上显示 |
|---|---|
| 扫码 / 点常用设备（还没按开始） | **已就绪** / 请在机器上按【开始】　按钮：取消 |
| 按【开始】出水 | **接水中** / 正在计量　按钮：结束接水 |
| 按【暂停】 | **接水暂停中** / 机器已暂停（「已接 N 秒」停住） |
| 按【结算】 | 跳到结算页，六行明细 |

一滴水没接就结算、或者直接点「取消」，显示 **接水已取消 / 未接水，未产生费用**，不会产生任何订单。

### 「暂停」是怎么认出来的

服务端没有暂停事件，`workStatus` 在暂停时仍然是 `2`（和正在出水一样）。唯一能看出差别的还是 `sync.amount`：**连着 3 轮（约 3.6 秒）它一动不动，而机器仍在这一单里**，那就是暂停了。恢复出水时它又开始涨，界面自己切回「接水中」。
